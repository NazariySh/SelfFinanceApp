# SelfFinance

A personal income/expense tracker: an ASP.NET Core Web API backend with a Blazor Server front end.

- [`asp-backend-webapi`](asp-backend-webapi) — the Web API (accounts, financial operations, reports)
- [`asp.net-core-blazor`](asp.net-core-blazor) — the Blazor Server UI that consumes the API

See each project's README for setup and run instructions.
